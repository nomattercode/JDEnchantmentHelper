ПОМОЩНИК ЗАЧАРОВАНИЯ JADE DYNASTY — ПЕРЕНОСИМАЯ ВЕРСИЯ
======================================================

Запуск:
  Дважды щёлкните jd-enchantment-helper.exe

Требуется 64-разрядная Windows 10/11.

При запуске Windows покажет запрос UAC. Финальный EXE содержит манифест
requireAdministrator; тестовые исполняемые файлы собираются без повышения прав.
Консольное окно не открывается.

OpenCV и его нативные зависимости статически встроены в EXE.
Среда выполнения MSVC также статически встроена.

На целевом компьютере НЕ нужны:
- DLL-файлы OpenCV
- vcpkg
- Rust или Cargo
- LLVM / Clang
- Visual Studio Build Tools
- отдельная установка Visual C++ Redistributable

Настройки программы хранятся отдельно в %APPDATA%\JDEnchantmentHelper.
