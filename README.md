# Помощник зачарования Jade Dynasty

Релизное приложение для автоматизированного зачарования предметов в Jade Dynasty.

## Смысл полного прохода

Значение «Полных проходов» — это количество полных обходов всех страниц инвентаря:

- **1 проход** — программа обходит все страницы и пытается зачаровать каждый предмет один раз, затем останавливается.
- **2 прохода** — после полного первого обхода возвращается на первую страницу и повторно обходит все страницы, но только для предметов, которые уцелели после первого прохода.
- Следующие проходы аналогично повторяют обработку оставшихся предметов. Если уцелевших предметов не осталось, программа останавливается досрочно.

Переключение страниц выполняется колёсиком мыши над инвентарём. Вверх — предыдущая страница, вниз — следующая. При запуске предполагается, что открыта первая страница.

## Первый запуск

1. Откройте Jade Dynasty и оставьте открытой первую страницу инвентаря.
2. Запустите приложение. Windows покажет запрос UAC: программа требует права администратора для управления курсором в игре.
3. В блоке **«Игровое окно»** выберите Jade Dynasty. В списке доступны небольшие статические миниатюры окон; кнопка обновления переснимает их.
4. В блоке **«Инвентарь»** нажмите **«Снять кадр и выделить сетку»**. Обведите мышью всю сетку от первой до последней ячейки.
5. После настройки снимок удаляется. Постоянного превью и фонового захвата нет.
6. При необходимости откройте **«Параметры сетки и распознавания»** и проверьте количество строк и столбцов, положение амулета и первую ячейку с предметами.
7. Справа выберите число **полных проходов** и нажмите **«Начать зачарование»**.

## Цикл зачарования

- Перед каждым предметом программа заново выбирает амулет правой кнопкой. Если предмет находится на другой странице, она временно возвращается к первой странице за амулетом и затем обратно к предмету.
- Для каждого предмета программа перепроверяет занятую ячейку, выбирает её правой кнопкой, ждёт активную синюю кнопку «Начать», затем нажимает её левой кнопкой и подтверждает результат через кнопку «ОК».
- После результата текущая страница инвентаря сканируется повторно. Пустые ячейки исключаются, уцелевшие предметы могут участвовать в следующем полном проходе.
- После последнего предмета страницы программа прокручивает инвентарь вниз. Смена страницы подтверждается сравнением двух снимков сетки.
- После последней страницы программа возвращается на первую страницу прокруткой вверх. Каждый переход подтверждается снимком сетки; если колесо не переключило страницу, программа останавливается и не начинает следующий проход на неправильной странице. Затем начинается следующий полный проход, если он был выбран и остались предметы.

## Управление

- **F12** — глобальная аварийная остановка.
- **Пауза / Продолжить** — приостанавливают и возобновляют серию.
- **Стоп** — прекращает серию.
- Справа отображаются текущий проход, страница, число обработанных и уцелевших предметов.
- Параметры сетки можно свернуть в блоке инвентаря; журнал событий также сворачивается.
- Игровое окно и настройки блокируются во время серии.
- Размер окна приложения фиксирован: 980×780; изменить размер мышью нельзя.
- После настройки сетки кадр освобождается. Постоянного превью, таблицы отладки, анализа произвольных файлов и сохранения диагностических изображений в релизной версии нет.
- Исполняемый файл запрашивает права администратора через встроенный Windows-манифест.

## Ограничения

Для определения смены страницы сравнивается уменьшенный визуальный отпечаток области сетки до и после прокрутки, устойчивый к небольшим изменениям подсветки и анимации. Если две соседние страницы содержат полностью одинаковое изображение в этой области, автоматически отличить их невозможно. Сканер определяет занятость слотов по контрасту изображения, а не по названию предмета.

Перед серией проверьте геометрию сетки, положение амулета и чувствительность распознавания. Держите игру видимой, не перекрывайте её и не перемещайте предметы вручную во время серии.

## Сборка и перенос

Для сборки на компьютере разработчика нужны Rust/MSVC, Visual Studio Build Tools, LLVM/Clang и vcpkg. OpenCV и MSVC Runtime используются статически.

Запустите:

```bat
scripts\build-test.bat
```

Тесты собираются без запроса UAC. Только финальное приложение собирается с feature `require-admin`, которая встраивает манифест `requireAdministrator`.

Скрипт проверяет форматирование, компиляцию и тесты, затем создаёт:

`dist\JD-Enchantment-Helper-Portable.zip`

На другом 64-разрядном ПК с Windows 10/11 распакуйте архив и запустите `run.bat`. Устанавливать OpenCV, vcpkg, Rust, LLVM или отдельный VC++ Redistributable на целевой компьютер не требуется. Windows покажет стандартный запрос UAC.

GitHub Actions настроен только на ручной запуск.
